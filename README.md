# Robô Programavel

## Sobre  
Este projeto foi desenvolvido para a disciplina de Robótica, com o objetivo de introduzir crianças ao mundo da programação e da robótica de forma interativa e prática. A ideia é tornar a aprendizagem divertida e acessível: as crianças programam o robô, aprendem conceitos de lógica, sensores, atuadores e veem o resultado físico do seu código em movimento.

## Objetivos  
- Permitir que os alunos/seus usuários aprendam os conceitos básicos de robótica (movimento, detecção de obstáculos, controle via Bluetooth ou outro meio) de forma simples.  
- Estimular o pensamento lógico, a criatividade e a resolução de problemas.  
- Facilitar que mesmo quem nunca programou antes consiga montar e controlar um robô.  
- Criar uma ponte entre o mundo virtual (o código) e o mundo real (o robô em ação).

## Funcionalidades  
- Controle de movimento do robô (avançar, recuar, girar) através de código.  
- Integração com sensores (dependendo da montagem) para detectar obstáculos ou seguir linha.  
- Controle via Bluetooth ou outro módulo de comunicação (se aplicável).  
- Possibilidade de expansão: adicionar novos sensores, modificações no hardware ou novos comandos de programação.

## Requisitos  
- Um robô físico ou montagem compatível com o hardware utilizado no projeto (por exemplo placas Arduino/ESP, motores, rodas, chassi, módulo Bluetooth ou similar).  
- Ambiente de desenvolvimento compatível (IDE, compilador) para a linguagem usada (C++ no repositório).  
- Software/hardware para upload do código no robô.
